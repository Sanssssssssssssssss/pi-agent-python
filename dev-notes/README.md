# Pi Agent for Python development notes

These files are historical build journals, parity evidence, and architecture records.
They are not a second user documentation site, and older files intentionally retain
the terminology used when they were written.

Start with:

- `pi-0.84.1-parity-ledger.md` for the verified behavior boundary.
- `architecture/index.md` for implementation records.
- `design/` for early design notes.
- `adr/` for durable architectural decisions.
- `release-process.md` for the current release gate.

Current user documentation lives in `README.md`, `README.zh-CN.md`, and the packaged
references under `src/pi_coding/data/docs/`.
